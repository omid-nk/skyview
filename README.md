# Skyview 🌤️

A modern and minimal weather app built with **Next.js** and **OpenWeather API**.

Search for any city and get current weather conditions in a clean, responsive interface with dynamic weather visuals.

## ✨ Features

- 🌍 Search weather by city
- 🌡️ Current temperature and weather conditions
- 🎨 Dynamic weather backgrounds and icons
- 📱 Fully responsive design
- ⚡ Fast and lightweight
- 🔎 City geocoding with OpenWeather API

## 🛠️ Tech Stack

- **Next.js**
- **React**
- **Tailwind CSS**
- **OpenWeather API**
- **Cloudflare**

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/omid-nk/skyview.git
cd skyview
```

Install dependencies:

```bash
npm install
```

Create a `.env.local` file:

```env
OPENWEATHER_API_URL=https://api.openweathermap.org
API_KEY=your_openweather_api_key
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
